# 术语表（需要你自己建）

这个目录里的两个文件是**空的**，因为每个人要翻的东西不一样，术语表得按自己的行业建。

## glossary.json —— 术语对照

```json
{
  "items": [
    { "en": ["MCB"], "zh": "微型断路器", "note": "表头缩写" },
    { "en": ["Distribution Board", "DB"], "zh": "配电箱", "note": "" }
  ]
}
```

- `en`：英文，可以写成数组放多个写法
- `zh`：中文
- `note`：备注，给你自己看的

## ambiguous.json —— 多义词的判据

```json
[
  {
    "en": "panel",
    "senses": [
      { "zh": "面板", "when": "指 LED 视频墙、显示屏的面板单元" },
      { "zh": "屏", "when": "指电气控制屏、AMF/ATS 切换屏" }
    ]
  }
]
```

- 一个词有几种意思，就写几条
- `when` 是判断依据，模型靠它选义项

## 怎么开始

1. 先空着跑一份文件，翻完点「新词 N 个」——它会把这个文件里术语表没有的词挑出来
2. 勾选，改好译法，加进去
3. 跑第二份，再加
4. 跑十几份之后，表就成型了

**别让程序自动写。** 错的术语会让后面所有文件都跟着错，每一条都该有人看过。
