# 保格式翻译 · 使用教程

> 一个把合同、报价单、工程量清单翻成另一种语言的工具。
> **排版原样保留**：字体、边框、表格、公式都不动，只换文字。
> 支持 `.xlsx`（Excel）和 `.docx`（Word），方向英→中 / 中→英。

---

## 一、先申请一个 API Key（只需一次）

翻译要用 AI，AI 是按用量收费的。**一份 300 条左右的清单大约 2 毛钱**，翻几十份也用不了几块钱。

软件支持好几家 AI 供应商，**任选一家有 Key 的就行**。下面先讲最便宜的 DeepSeek，后面附其他几家。

### 1. 打开网站

浏览器访问：**https://platform.deepseek.com**

（这是 DeepSeek 的开放平台，不是聊天那个网页版。）

### 2. 注册并登录

用手机号注册，跟普通网站一样。

### 3. 充值（先别急，可能不用充）

**注册就送 6 元体验金。**

6 块钱听着不多，但只拿来翻译能用很久——一份 88 条的清单才 5 分钱，6 元能翻一百多份。**先用赠金就行，花完了再考虑充不充。**

赠金用完之后：

- 想继续用 → 充个十块二十块，能用几个月
- **不想充值** → 有两个选择：
  1. 切到「本地翻译」（文件不出内网，但质量差一档，见第五节）
  2. **找开发者要一个 Key**，先用他的额度

> 赠金有没有期限，以平台页面显示为准。注册完进「账户余额」看一眼就知道了。

### 4. 创建 API Key

- 左侧菜单找到 **API Keys**
- 点「创建 API Key」
- 随便起个名字，比如 `翻译`
- 点确定

### 5. 复制并保存

**创建完只会显示一次**，那串 `sk-` 开头的东西就是 Key。

⚠️ 立刻复制，存到记事本里。关掉页面就再也看不到了，只能重新建一个。

### 6. 填进软件

打开软件，页面底下有一行小字「**更换翻译供应商 / 填 API Key**」，点开。

1. 下拉里选 **DeepSeek**
2. 把 Key 粘进去
3. 点保存

**只需要填一次**，以后不再问。

> 每个人的 Key 各自保管。**别把 Key 发到群里**——谁拿到都能花你的钱。

## 二、安装

### 1. 解压

把压缩包解压到电脑上任意位置，比如 `D:\保格式翻译`。

> ⚠️ **整个文件夹一起用。** 里面那个 `_internal` 文件夹是程序本体，只把 exe 拖出来是跑不起来的。

### 2. 双击

双击 **`保格式翻译.exe`**。

会弹出一个叫「保格式翻译」的窗口。第一次打开可能慢几秒，等一下。

> 如果没弹出来，看任务栏是不是被挡住了；再不行重启一次电脑。

## 三、翻译一个文件

1. 把文件**拖到虚线框里**（或者点一下框选择文件），可以一次放好几个
2. 上面选语言方向：**英 → 中** 或 **中 → 英**
3. 等进度条走完（会显示「翻译中 42 / 88 条」）
4. 点「下载译文」

翻完之后，那行下面还会多几个按钮：

| 按钮 | 是干什么的 |
|---|---|
| **下载译文** | 拿成品 |
| **回译体检** | 把译文再翻回原文语言，跟原文比，找出可能翻歪的句子 |
| **逐条改** | 左边原文、右边译文，直接改字，改完重新下载就是新版 |
| **看可疑的** | 只看系统挑出来的可疑条目（数字对不上、术语没用表里的、漏译的） |
| **发现新词** | 把这份文件里术语表没收录的词挑出来，你勾选后加进去 |
| **一键重译** | 把那几条可疑的送回去重翻 |

### 两个开关

**双语对照**：勾上后，原文和译文放在同一个格子里（原文在上、译文在下）。给领导看、或者自己核对时用。Word 暂不支持。

**引擎**：

- **云端翻译**（默认）：质量最好，一份约 2 毛钱
- **本地翻译**：重要文件防泄漏用这个，翻译会稍差（见下一节）

## 四、文件转换（另一个页签）

软件顶上还有第二个页签：**文件转换**。它能把 PDF 转 Word、Word 转 PDF、图片换格式…… 一共 270 种格式。

### 为什么会有这个

因为客户发来的合同常常是 **PDF**，翻译不了。用它转成 Word，再翻。

```
PDF（客户发来的） → 文件转换 → Word → 合同翻译 → 保格式的中文 Word
```

### 怎么用

1. 点顶上的「**文件转换**」
2. 把文件拖进去（也可以一次拖好几个）
3. 下面选要转成什么：PDF / DOCX / XLSX / PPTX / PNG / JPG / WEBP / TXT / CSV / HTML / EPUB / MD
4. 转完点「下载」

### 要知道的

- **转换在本机完成**，文件不上传、不花钱、断网也能用
- 快：Word 转 PDF 大约 1–5 秒
- 这个引擎是开源项目 [Filee](https://github.com/KnifeLemon/Filee)，MIT 协议，跟着软件一起装好了
- 少数特殊格式（比如 PDF 里带公式、扫描件）转出来可能不完美——它擅长的是常规文档

## 五、本地翻译（防泄漏）

这个模式**文件不出公司内网**，适合不能外发的合同。

### 什么情况用

- 合同里有甲方乙方真名、金额、违约条款，公司不允许传到外部服务器
- 断网环境

### 怎么用

1. 勾选「本地翻译」
2. 下面会出现「本地模型地址」这一栏
3. 填入管理员给你的地址（比如 `http://192.168.1.100:11434`）
4. 点保存

保存后，再翻译就走那台机器了。

### 要注意的

- **质量会差一档**，长句容易翻散。重要文件建议翻完人工再过一遍，或者点「回译体检」查一遍
- **那台机器得开着**，关了就用不了
- **一次只能一个人翻**，别人在翻的时候你得排队
- 地址要不到？说明你这台机器不能连内网那台，那就先用云端

## 七、常见问题

**Q：填了 Key 还是报错「余额不足」？**
去 platform.deepseek.com 看一下账户余额，充值后等一两分钟再试。

**Q：提示「端口被占用」？**
上次的程序没关干净。任务管理器里找「保格式翻译」，结束掉再重开。

**Q：杀毒软件报警？**
自己打包的小工具没有数字签名，个别杀毒软件会敏感。加信任即可。

**Q：翻出来格式乱了？**
不应该乱——程序只改文字，其他一个字节没动。真乱了把文件发给管理员看。

**Q：能翻 PDF 吗？**
暂时不能。先转成 Word 再翻。

**Q：术语表能加词吗？**
能。翻译完点「发现新词」，它会把表里没有的词挑出来，你勾选、改好译法，加进去就行，以后所有文件都按新表来。

**Q：怎么知道哪句翻得不对？**
点「回译体检」。它会翻回去跟原文比，把走样的句子列出来。**注意：这是线索不是判决**——列出来的不一定错，只是值得看一眼。

## 八、出问题找谁

把这三样发给管理员：

1. 出问题的那个文件
2. 屏幕上弹出的提示内容（截图也行）
3. 软件目录下的「运行日志.txt」

有这三样，问题基本能定位。
